# 官网介绍视频 · 设计方案

日期：2026-09-25
状态：待确认

## 1. 目的

给 qiaobit.com 做一支介绍视频，放在官网首屏正下方的新区块里。访客往下滚一屏，就能用 74 秒看懂桥比特是谁、做哪三件事、有什么成绩、造过哪些东西，再决定继续往下看什么。

**已确认的决定（来自对话）：**

- 新增独立区块，不替换关于区现有的「44 秒认识桥比特」视频
- 声音：只有配乐和画面大字，没有人声
- 制作方式：用 HyperFrames 把官网素材做成动态图形片，不用 AI 生成画面
- 画面文字全部用中文，不加英文副标题；只保留品牌字标 TECH BRIDGE 和产品原名
- 「企业服务」数据写 **100+**
- 配乐：曲B（HeyGen 曲库，曲目编号 `f0bcd9784c4842d286032f56d2a79394`）
- 位置：首屏（`#hero`）正下方、关于区（`#about`）之前

**不做的事：** 不改官网其它区块的文字和数据；不做竖屏版；不做英文版视频。

## 2. 视频规格

| 项 | 值 |
|---|---|
| 画幅 | 横屏 16:9，按 1920×1080 制作 |

## 4. 制作工程

- 视频工程单独放在 `../Techbridge官网介绍视频/`，是一个 HyperFrames 工程，不放进官网仓库，避免源文件被一起部署。
- 素材从官网仓库复制进工程的 `assets/` 目录，不改动官网里的原文件。
- 配乐来源记录在工程的 `.media/manifest.jsonl` 里，包含曲目编号、搜索词、获取账号类型。

## 5. 上线到官网

**交付文件**（放在官网仓库根目录，跟现有视频文件的放法一致）：

- `site-tour.mp4`：H.264 编码加 AAC 音频，1920×1080，开启快速起播，目标体积 ≤ 10MB
- `poster-site-tour.webp`：封面图，取字标完整出现的那一帧

**页面结构**：在 `index.html` 的 `#hero` 和 `#about` 之间新增 `<section id="tour" class="section-site-tour">`：

- 小标签「官网导览 · 01:14」，标题「74 秒看懂桥比特.」，一句说明文字；中英文文案都照官网现有的 `data-lang` 写法各写一份（中英切换是官网已有功能）
- `<video controls playsinline preload="none" poster="poster-site-tour.webp">`：不自动播放，点了才加载，不影响首屏速度
- 样式写在 `style.css`，沿用 `.about-profile-film` / `.intro-video-wrapper` 的视觉语言，手机宽度下单列排布

**测试**：新增 `tests/site-tour.test.mjs`，检查新区块在 `#hero` 之后、`#about` 之前，视频和封面文件存在，视频设置为 `preload="none"`。

## 6. 验证

1. HyperFrames 自带检查（`npm run check`）通过
2. 渲染后抽帧做成缩略图总览，逐场景核对文字、素材、有没有溢出画面
3. 核对音画：时长、渐收位置、文件体积
4. 本地起官网，用内置浏览器分别在桌面和手机宽度下截图，确认区块位置、封面、播放都正常，控制台没有报错
5. 官网仓库 `npm run check` 和 `npm run deploy:dry-run` 通过

## 7. 风险与待确认

- **配乐授权**：HeyGen 公开说曲库大多免版税，但没找到明确条款写能不能用在 HeyGen 之外的官网上做商用。建议在 HeyGen 后台或客服那里确认一句。确认有问题时，换成条款明确的曲库，分镜不用改。
- **数据前后不一致**：视频写「100+ 企业服务」，官网数据栏还是「5500+」，时间线写的是「累计服务 5500 家企业」。本方案不改官网文字，要不要统一，另外确认。
- **上线发布**：官网仓库当前分支上有别人未提交的改动（`brand-motion`、`product-parallax`、浦东照片等），这次只提交本方案相关的文件。推送和部署到线上前先跟用户确认。
